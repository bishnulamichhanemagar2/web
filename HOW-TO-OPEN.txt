📱 OPEN ON OTHER DEVICES (Phone, Tablet, Another Computer)
═══════════════════════════════════════════════════════════════

1. Right-click on "start-network.ps1" in this folder
2. Select "Run with PowerShell"
3. Wait for both server windows to open (about 10 seconds)

✓ Your website will open automatically on this computer
✓ Other devices can access it too!


📲 TO ACCESS FROM YOUR PHONE/TABLET:
───────────────────────────────────────────────────────────────

1. Make sure your phone/tablet is on the SAME WiFi network as this computer
   (Both must be connected to the same WiFi: "Your WiFi Name")

2. Open any browser on your phone/tablet (Chrome, Safari, etc.)

3. Type this address in the browser:

   ┌─────────────────────────────────┐
   │  http://192.168.1.67:5173       │
   └─────────────────────────────────┘

4. Press Enter/Go and the website will load!


💻 TO OPEN ON THIS COMPUTER ONLY:
───────────────────────────────────────────────────────────────

Just open your browser and go to:
   http://localhost:5173


⚠️ IMPORTANT NOTES:
───────────────────────────────────────────────────────────────

• Keep BOTH PowerShell windows open while using the website
• To stop the website: Close both PowerShell windows
• If the IP address doesn't work, your computer's IP might have changed
  (This can happen after restarting your router or computer)


🔧 TROUBLESHOOTING:
───────────────────────────────────────────────────────────────

Problem: "Can't access from phone"
Solution: 
  - Make sure both devices are on the same WiFi
  - Check if Windows Firewall is blocking (it should already be allowed)
  - Try restarting the servers

Problem: "IP address not working"
Solution:
  - Your computer's IP address might have changed
  - Run start-network.ps1 again - it will show the new IP address
